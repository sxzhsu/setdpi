Etsy Print Sizes at 300 DPI: The Pixel Cheat Sheet

Most printable-art shops sell one file per ratio and let buyers pick a frame. Size each file for the largest print in its ratio — it scales down cleanly to every smaller size. Here's what 300 DPI actually means in pixels.

Ratio Common frame sizes (in) Pixels at 300 DPI (largest size)
2:3 4×6 · 8×12 · 12×18 · 16×24 · 20×30 · 24×36 7200 × 10800 px
3:4 6×8 · 9×12 · 12×16 · 18×24 5400 × 7200 px
4:5 8×10 · 16×20 4800 × 6000 px
11:14 11×14 3300 × 4200 px
ISO (A-series) A5 · A4 · A3 · A2 · A1 A4 = 2480 × 3508 · A3 = 3508 × 4961 px
5:7 5×7 1500 × 2100 px

Watch the 20 MB cap. A 24×36 JPG at 300 DPI can land over 20 MB. Export it as a high-quality JPG (not PNG) and check the size before you set DPI — we won't make the file bigger, but we can't make it smaller either.

Short on pixels? Upscale in your design app first (Photoshop's Preserve Details 2.0, or your AI upscaler), then set 300 DPI here.

Etsy Seller FAQ

Will my file still fit under Etsy's 20 MB limit?
Yes, if it fit before. SetDPI changes a few bytes of metadata, so the file size stays essentially identical. If your file is already over 20 MB, re-export it as a high-quality JPG first — changing DPI won't shrink it.
Does changing DPI change my pixel dimensions?
No. A 4800 × 6000 file stays 4800 × 6000. Only the DPI tag changes — which is exactly what you want for a printable you've already sized.
My buyer says the print came out blurry. Will 300 DPI fix it?
Only if the pixels are there. DPI tells the printer how big to print; pixels decide how sharp it looks. If you're selling a 16×20 file, it needs 4800 × 6000 pixels. Check the chart above. If you're short, upscale first, then set the DPI.
Is it safe to drop my original artwork here?
Your files never leave your computer. The conversion runs in your browser — nothing is uploaded to us or anyone else. Turn off your Wi-Fi after the page loads and it still works.
My Canva download says 96 DPI. Is it print-ready?
Canva tags PNG and JPG downloads at 96 DPI no matter how big the design is. If you built the design in pixels (for example 2400 × 3000 px for an 8×10), the pixels are already there and only the tag is wrong. Set it to 300 here. If you built it in inches, check the pixel size first: a low pixel count won't get sharper with a new tag. Re-export with a larger size, or use Canva's PDF Print option.
